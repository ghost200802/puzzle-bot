# Step 6：目标图匹配与对齐

## 目标

将 Step 5 的求解结果与用户提供的拼图目标图（包装盒照片）进行对齐，验证每块拼图在目标图上的位置是否正确，并为每块生成 NCC（归一化互相关）匹配置信度。

---

## 输入

- `6_solution/` 目录：Step 5 的求解结果
- 目标图文件路径（`--target` 参数）
- `4_deduped/`：去重后的边 JSON
- `2_piece_colors/`：拼图块彩色 PNG

---

## 处理流程

### 6.1 Phase 1：生成装配图

根据求解结果生成拼图的装配预览图：

1. 从 `solution_grid.txt` 解析每块拼图的网格位置和旋转方向
2. 从 `solution_meta.json` 读取拼图尺寸 (W, H)
3. 利用每块拼图的边 JSON 数据计算其在装配坐标系中的变换（旋转+平移）
4. 将所有拼图块的彩色图像变换后绘制到统一画布上
5. 记录画布信息（网格偏移、单元格尺寸等）用于后续对齐

### 6.2 Phase 2：目标图校正与对齐

将目标图（可能倾斜、有透视变形）校正并对齐到装配图的坐标系：

1. **检测目标图边界**：在目标图上检测最大的四边形轮廓（拼图区域边界）
   - Canny 边缘检测 + 形态学膨胀 + 轮廓查找 + 多边形近似
2. **透视校正**：将检测到的四边形通过透视变换映射为矩形
3. **方向判定**：比较校正后目标图与装配图网格的宽高比：
   - 如果直接方向更接近则不旋转
   - 如果旋转 90° 更接近则先旋转 90°
4. **翻转判定**：分别计算 0° 和 180° 翻转后目标图与装配图区域的 NCC，取 NCC 更高的方向
5. **保存对齐结果**：将对齐后的目标图保存为 `target_aligned.png`

### 6.3 Phase 3：逐块 NCC 匹配

对每块已放置的拼图块，在目标图的对应位置搜索最佳匹配：

1. **计算拼图块变换**：根据求解结果中的位置和方向，计算该块在对齐目标图上的预期位置
2. **平移搜索**（粗+精两阶段）：
   - 粗搜索：以 4 像素为步长，在 ±40 像素范围内搜索最佳平移偏移
   - 精搜索：在粗搜索最优点附近 ±5 像素范围内逐像素搜索
   - 评分方式：对拼图块掩码（腐蚀后）覆盖区域计算 NCC
3. **旋转搜索**：在最佳平移位置，尝试 ±5° 范围内的旋转（步长 0.5°），寻找进一步提升 NCC 的角度
4. **直方图匹配 NCC**：在最终位置，对拼图块像素进行 CDF 直方图匹配后重新计算 NCC，消除光照差异
5. **最终得分**：取原始 NCC 和直方图匹配 NCC 中的较大值

### 6.4 Phase 4：置信度评估

对每块的匹配结果进行置信度评估：

- 得分 ≥ 0.7 的块标记为"高置信度"（`refined: true`）
- 得分 < 0.7 的块标记为"低置信度"（`refined: false`）

### 6.5 Phase 5：报告与可视化

1. **匹配报告**（`target_match_report.json`）：每块的网格位置、方向、NCC 得分、平移偏移、旋转角度、置信度
2. **匹配可视化**（`target_match_visual.png`）：在对齐目标图上叠加拼图块图像，用颜色边框标注置信度（绿色 ≥ 0.7，青色 ≥ 0.4，红色 < 0.4）

---

## 并行处理

Phase 3 的逐块匹配使用多线程并行（`ThreadPoolExecutor`），线程数为 `min(8, CPU核心数)`。

---

## 输出

| 输出文件 | 内容 |
|---------|------|
| `target_aligned.png` | 校正并对齐后的目标图 |
| `target_match_report.json` | 每块的 NCC 匹配报告和置信度 |
| `target_match_visual.png` | 匹配结果可视化叠加图 |

---

## 关键参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 置信度阈值 | 0.7 | 高/低置信度的分界线 |
| 搜索范围 | ±40 像素 | 平移搜索的范围 |
| 粗搜索步长 | 4 像素 | 粗搜索的步长 |
| 旋转搜索范围 | ±5° | 旋转微调的范围 |
| 旋转搜索步长 | 0.5° | 旋转微调的步长 |

---

## 后续步骤依赖

Step 7（目标引导求解）读取 `target_match_report.json` 中的置信度，以高置信度块作为固定锚点，对低置信度和未放置的块进行重新求解。
