# Step 5：DFS 求解

## 目标

利用连通图中的边匹配关系，通过深度优先搜索（DFS）找到拼图块的正确排列，将所有块放置到一个 W×H 的网格中。

---

## 输入

- `5_connectivity/connectivity.json`：边匹配连通图
- `5_connectivity/piece_edge_info.json`：拼图块边类型标记
- `5_connectivity/texture_verify_report.json`：NCC 纹理验证报告（如果存在）
- `4_deduped/`：去重后的边 JSON 文件

---

## 处理流程

### 5.1 连通图增强：NCC 优先排序

如果存在纹理验证报告，对连通图中的匹配进行 NCC 增强：

1. **复合误差计算**：对每个匹配条目，如果存在 NCC 数据且未被拒绝，则计算复合误差 = 几何误差 / (NCC × 权重)
2. **优先排序**：将匹配列表按复合误差排序，NCC 验证通过的匹配排在前面
3. **回退列表**：无 NCC 数据的匹配按原始几何误差排在后面

这样求解器会优先尝试纹理验证通过的匹配，提高求解效率。

### 5.2 拼图尺寸推断

自动推断拼图的宽高（W × H）：

1. **角块识别**：找出所有拥有 ≥ 2 条平边的拼图块作为角块
2. **边链追踪**：从每个角块出发，沿非平边方向追踪边块链：
   - 每一步选择匹配误差最小的边块候选
   - 遇到下一个角块（≥ 2 条平边）时停止
   - 记录链上经过的拼图块数量
3. **尺寸确定**：统计所有角块的两个方向追踪结果，取最频繁的 (W, H) 对
4. **回退策略**：如果追踪失败，根据拼图块总数进行因数分解推断

### 5.3 DFS 求解

使用螺旋式 DFS 从角块开始搜索：

1. **起始块选择**：按匹配数从多到少排序所有角块，依次尝试
2. **螺旋填充策略**：
   - 第一阶段：从起始角块出发，沿边框构建外圈边框链
   - 第二阶段：外框完成后，从外向内螺旋式填充内部块
3. **约束检查**（`can_place`）：
   - 目标位置必须在网格范围内
   - 该拼图块尚未被放置
   - 该位置的所有已放置邻居，其对应边的匹配列表中包含当前块
   - 方向（orientation）必须与所有邻居一致
4. **回溯**：当无法继续放置时，回溯到上一个选择点尝试其他候选
5. **里程碑保存**：在求解过程中定期保存中间结果（网格文本、SVG、装配图）

### 5.4 多角块尝试

由于起始角块的选择影响求解结果：

1. 依次尝试每个角块作为起始点
2. 对每次尝试记录放置的拼图块数量
3. 如果某次尝试得到完整解（所有块都放置），立即停止
4. 否则取放置数量最多的解作为最佳解

### 5.5 求解评估

对最终解方案进行质量评估：

1. **覆盖率**：已放置块数 / 总格数
2. **匹配边数**：相邻已放置块之间确实匹配的边数 / 理论最大匹配边数
3. **匹配质量**：所有已匹配边的平均误差

## 输出

| 输出文件 | 内容 |
|---------|------|
| `6_solution/solution_grid.txt` | 文字版解方案网格，每格显示 `{pid}{方向箭头}` |
| `6_solution/solution_meta.json` | `{width, height}` 拼图尺寸 |
| `6_solution/assembly.png` | 拼图装配预览图 |
| `6_solution/solution.svg` | SVG 格式装配图 |
| `6_solution/milestone/` | 求解过程各阶段的快照 |

---

## 关键参数

| 参数 | 说明 |
|------|------|
| NCC 权重 | 1000.0，NCC 复合误差中的权重因子 |
| 最大边框搜索迭代 | 50000 |
| 最大总迭代 | 200000 |
