# Step 3：重复拼图块检测与去除

## 目标

从所有提取的拼图块中识别并去除重复出现的块。同一块拼图可能在多张照片中出现，需要识别出这些重复并只保留质量最好的一个版本。

---

## 输入

- `3_vector/` 目录：所有拼图块的边 JSON 数据
- `2_piece_colors/` 目录：所有拼图块的彩色 PNG 图像

---

## 处理流程

### 3.1 拼图块签名分组

对每块拼图计算一个签名，将签名相同的块分到同一组：

1. **边类型分类**：对每条边判断其凸凹类型（平边 F、凸边 T、凹边 B）
2. **签名生成**：得到一个 4 元组，如 `(F, T, B, T)` 表示四条边依次为平-凸-凹-凸
3. **归一化**：对签名进行循环旋转归一化，消除旋转带来的差异
4. **分组**：按 `(平边数量, 归一化签名)` 分组

只有签名相同的拼图块才可能是重复，大幅缩小后续比较的范围。

### 3.2 几何匹配（粗筛）

在同一签名组内，对所有块对进行几何形状比较：

1. **四旋转遍历**：尝试 4 种旋转对齐方式（0°、90°、180°、270°）
2. **逐边比较**：对每种旋转，将两块拼图的四条边一一对应比较
   - 跳过两条都是平边的对（无法区分）
   - 检查对应边长度比是否大于阈值（默认 0.65）
   - 计算对应边的轮廓剖面 RMSE（将边重采样为 50 个点，比较法线方向偏移量）
3. **匹配判定**：如果所有非平边对的 RMSE 均低于阈值（默认 0.08），则几何匹配通过
4. **记录最优旋转**：取总 RMSE 最小的旋转方式

### 3.3 纹理验证（精筛）

对几何匹配通过的块对，进一步用彩色图像进行纹理验证：

1. **单应性变换**：利用两块拼图四个角点的对应关系，计算单应性矩阵（Homography），将块 B 变换到块 A 的坐标系
2. **重叠区域提取**：在变换后的图像中，取两块拼图透明通道重叠的区域
3. **直方图匹配**：对重叠区域的灰度值进行 CDF 直方图匹配，消除光照差异
4. **NCC 计算**：计算归一化互相关（NCC），同时计算灰度 NCC 和边缘 NCC（Canny 边缘检测后），取较大值
5. **确认判定**：NCC ≥ 阈值（默认 0.65）则确认为重复

### 3.4 并查集合并

使用并查集（Union-Find）数据结构管理重复关系：

1. 所有确认的重复对通过 `union` 操作合并到同一集合
2. 最终形成若干等价类，每个等价类代表同一个物理拼图块

### 3.5 选优

在每个等价类中选择一个最佳代表：

- **评分标准**：计算每块拼图彩色图前景区域的对比度（灰度标准差）
- **选择最高对比度的块**：对比度高意味着图像更清晰、细节更丰富
- 仅保留最佳代表的边 JSON 文件，复制到 `4_deduped/` 目录

---

## 并行处理

- 几何匹配和 NCC 纹理验证均使用多进程并行（`ProcessPoolExecutor`）
- 工作进程数为 `min(CPU核心数-2, 14)`

---

## 输出

| 输出 | 内容 |
|------|------|
| `4_deduped/` | 去重后的边 JSON 文件（仅包含每类重复中的最佳代表） |
| `__check/dedup_match_meta.json` | 所有块对的匹配元数据（RMSE、NCC、是否确认） |

---

## 关键参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 边剖面 RMSE 阈值 | 0.08 | 几何匹配的最大允许误差 |
| 边长度比阈值 | 0.65 | 对应边最短/最长之比的下限 |
| NCC 阈值 | 0.65 | 纹理验证的最低相关系数 |
| 边重采样点数 | 50 | 计算边剖面时的等距采样数 |

---
